# Administrador de tareas

Tres versiones educativas de un administrador de tareas. Se conservan juntas para mostrar su evolución: implementación inicial, versión 2 y versión 3 con JSON.

## Archivos

- `Administrador-de-tareas.py`: versión inicial.
- `administrador-de-tareas-v2.py`: segunda versión.
- `administrador-de-tareas-v3-json.py`: versión con almacenamiento JSON.
- `notas/Readmee administrador de tareas v2.txt`: notas originales.

Las versiones que usan Excel requieren `openpyxl` (`pip install -r requirements.txt`). Los archivos de datos locales no se incluyen. Ejercicios educativos en progreso; no se declara una suite de pruebas.
